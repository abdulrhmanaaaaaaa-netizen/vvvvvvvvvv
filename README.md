# APEX DRIVE — Native WebGL2 Offline Game

نسخة جديدة من الصفر، لا تستخدم Three.js أو Babylon أو Phaser أو أي مكتبة أو إطار عمل خارجي. محرك الرسم مكتوب مباشرة باستخدام WebGL 2 وJavaScript الأصلي، وكل الشيفرات والبيانات المطلوبة موجودة داخل المشروع.

## ما المقصود بعدم وجود مكتبات؟

- لا يوجد `node_modules` ولا npm dependencies.
- لا توجد CDN أو روابط خطوط أو صور أو موديلات خارجية.
- لا توجد طلبات API أو تحليلات أو اتصالات خارجية في مسار اللعب.
- ملفات JavaScript المحلية (`engine.js`, `world.js`, `game.js`) هي شيفرة المشروع نفسه وليست مكتبات خارجية.
- المجسمات الحالية هندستها تُبنى محليًا داخل اللعبة كـ meshes ثلاثية الأبعاد؛ لا يتم جلبها من الإنترنت.

## التشغيل محليًا

من داخل المجلد:

```bash
python3 -m http.server 8080
```

ثم افتح `http://localhost:8080`.

لا تحتاج إلى Node.js أو تثبيت أي حزمة. يجب تشغيله عبر HTTP/HTTPS حتى يعمل Service Worker؛ فتح `index.html` مباشرة عبر `file://` لا يتيح التخزين دون اتصال في معظم المتصفحات.

## النشر على موقعك

ارفع محتويات المجلد إلى جذر المستودع، ثم انشره عبر استضافتك الثابتة على HTTPS. عند أول زيارة تُحمّل ملفات المشروع من نطاق موقعك فقط. بعد اكتمال تحميل Service Worker وتخزين ملفات التطبيق، يمكن فتحه دون اتصال بالإنترنت من المتصفح/الشاشة الرئيسية.

مهم: الموقع المستضاف على الإنترنت يحتاج اتصالًا في أول زيارة حتى يصل إليه المتصفح ويحمّل الملفات. بعد التخزين المحلي يمكن تشغيل النسخة المخزنة دون اتصال. تحديثات اللعبة تحتاج اتصالًا مرة أخرى لتصل إلى الجهاز.

## ما الموجود في النموذج

- محرك رسم أصلي WebGL 2، مع هندسة مثلثية، إضاءة اتجاهية، ضباب مسافة، وجودة عرض قابلة للتعديل.
- خمسة مسارات: مدينة، صحراء، ساحل، مرتفعات، وحلبة مغلقة.
- طرق منحنية ثلاثية الأبعاد، خطوط حارات، أكتاف، حواجز، مبانٍ، نوافذ، أعمدة إنارة، أشجار نخيل، صخور، تلال، أكشاك، توك توك وسيارات مرور.
- أربع تشكيلات سيارات هندسية: GT رياضية، سيدان، SUV، وتاكسي؛ كل واحدة مجسم ثلاثي الأبعاد يتكون من هيكل وزجاج ومصابيح وعجلات وجنوط وتفاصيل خارجية.
- قيادة أركيد على مسار، دواسة بنزين وفرامل ونيترو، تحكم لمس وعجلة افتراضية وتحكم لوحة مفاتيح، وثلاث زوايا كاميرا.
- تخزين PWA محلي عبر Service Worker.

## حدود النسخة بوضوح

هذه قاعدة تقنية مستقلة قابلة للتوسيع، وليست منتجًا نهائيًا بمستوى ألعاب AAA. المجسمات الحالية مبنية هندسيًا داخل الشيفرة ومظهرها stylized/low-to-mid poly، وليست سيارات ممسوحة ضوئيًا أو موديلات سيارات إنتاجية فائقة التفاصيل. نظام القيادة حاليًا أركيد مبسط، ولا توجد بعد محاكاة تعليق وإطارات واصطدامات معقدة، أو خرائط ضخمة مبنية من مسح واقعي، أو أصوات مسجلة احترافية.

الوصول إلى مستوى بصري عالمي يتطلب إنشاء/شراء/إنتاج موديلات عالية التفاصيل وخامات PBR وخرائط بيئية عالية الجودة وتحسينها للويب، ثم تضمين الملفات محليًا داخل المشروع. يمكن فعل ذلك دون أي مكتبة runtime: يُكتب قارئ تنسيق الأصول داخل المحرك أو تُحوّل الأصول مسبقًا إلى تنسيق داخلي. عدم استخدام مكتبات لا يعني أن أصول اللعبة يجب أن تكون بدائية، لكنه يجعل بناء المحرك وتحميل الأصول مسؤولية المشروع نفسه.

## البنية

- `index.html` الواجهة.
- `src/engine.js` محرك WebGL 2 ومولد الهندسة والدوال الرياضية.
- `src/world.js` المسارات والعوالم والسيارات الهندسية.
- `src/game.js` الحركة والتحكم والكاميرا وواجهة اللعب.
- `src/styles.css` التنسيق.
- `sw.js` التخزين المؤقت والعمل دون اتصال.
- `manifest.webmanifest` تعريف تطبيق الويب.
